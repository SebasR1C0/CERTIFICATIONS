# Ruta de estudio PortSwigger (BSCP)

## Fase 1: Base
1. **Essential skills**: uso del scanner y de los puntos de inserción. Te ahorra mucho tiempo en el examen.
2. **Information disclosure**: probabilidad media.
3. **Path traversal**: media.
4. **Access control**: alta.
5. **Authentication**: muy alta.
6. **SQL injection**: muy alta.

## Fase 2: Lado cliente (etapa 1)
7. **Cross-site scripting (XSS)**: muy alta.
8. **DOM-based vulnerabilities**: alta.
9. **CSRF**: alta.
10. **CORS**: media-baja.
11. **Clickjacking**: baja.

## Fase 3: Lado servidor (etapa 3)
12. **OS command injection**: media-alta.
13. **File upload vulnerabilities**: alta.
14. **SSRF**: alta.
15. **XXE**: alta.
16. **Server-side template injection (SSTI)**: muy alta.
17. **Insecure deserialization**: alta.

## Fase 4: Avanzado
18. **HTTP Host header attacks**: alta.
19. **Web cache poisoning**: alta.
20. **HTTP request smuggling**: muy alta.
21. **JWT attacks**: alta.
22. **OAuth authentication**: media-alta.
23. **Prototype pollution**: media.

## Fase 5: Menor probabilidad
24. **Business logic vulnerabilities**: media-baja.
25. **NoSQL injection**: media-baja.
26. **API testing**: baja-media.
27. **GraphQL API vulnerabilities**: baja-media. Conviene hacerla después de API testing.
28. **WebSockets**: baja.
29. **Race conditions**: baja.
30. **Web cache deception**: baja.
31. **Web LLM attacks**: muy baja.
